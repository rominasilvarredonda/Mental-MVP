# Mental v2

Migración del MVP HTML a Next.js, React, TypeScript, Tailwind y Supabase, sin depender del HTML original en tiempo de ejecución.

## Ejecutar

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

Abrí `http://localhost:3000`.

## Variables de entorno

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```
